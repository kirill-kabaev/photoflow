## Этап 1. Проверенный сквозной Codex-assisted workflow

Статус: выполнен 16.11.2026. 45 тестов проходят с реальным Sony ARW;
настоящий Codex-анализ и v001 оставлены на review. [Доказательства и ограничения](./implemented_stage_1.md).

Объединяет необходимые части фаз 1, 2, 3, 4 и 5 спецификации, чтобы получить
работающий цикл вместо отдельных заготовок.

Результат: CLI → очередь → RAW-превью → ручной handoff Codex → строгий импорт
AI-плана → обработка оригинала → v001 и Markdown → feedback → v002 → AI review
→ явное одобрение пользователя → JPEG и TIFF 16 бит с ICC.

Критерии приёмки:

- Все требуемые CLI-команды выполняются локально, возвращают JSON, не загружают изображения.
- Сканирование идемпотентно; переходы валидируются; JSON записывается атомарно под flock.
- Конфликты имён, симлинки, traversal, чужие рецепты и неизвестные операции отклоняются.
- Каждая версия содержит реальные before/after, рецепт, анализ, метрики и манифест.
- RAW проверяются SHA-256; история версий и feedback сохраняются.
- Экспорт требует одобрения конкретной версии и повторно обрабатывает RAW.
- Автотест проходит весь цикл с синтетическим декодером и явно тестовым AI.
- Sony ARW отдельно проверен настоящим LibRaw; выполнена настоящая визуальная оценка Codex.
- Реальные пользовательские фотографии остаются на review, без автоматического одобрения.

## Этап 2. Семантическая локальная ретушь

- Подобрать и отдельно проверить локальную модель сегментации с лицензией и контрольной суммой весов.
- Маски кожи/глаз/губ/волос/одежды; исключение губ и постоянных особенностей из коррекций.
- Импорт внешних растровых масок, ревизия масок по overlay, локальные detail-превью.
- Оценка пор и границ на реальных портретах, документированные ограничения модели.

Приёмка: модель действительно выполняется offline; сохранены float-маски и версия модели;
масштабирование координат проверено; неподдерживаемые классы не подменяются эллипсами.

## Этап 3. Опциональный API Director и ограниченный цикл качества

- Только явное согласие на передачу уменьшенных превью; ключи через окружение.
- Провайдер с vision и строгим JSON, реальные таймауты, ограниченные повторы.
- Лимиты запросов/стоимости/инструментов, максимум два полноразмерных прохода.
- Контроль общего стиля по одобренному референсу и документирование отклонений.

Приёмка: отдельные mock-тесты сетевых ошибок и бюджетов; реальный smoke-тест только
при предоставленных настройках и разрешении. Никаких автоматических одобрений.

## Этап 4. Производственная надёжность и качество

- Больше камер/ориентаций, ограничение памяти, измерения времени и проверка на WSL2.
- Fault injection на каждой границе транзакций; удобное восстановление частичного экспорта.
- Расширенное сохранение безопасных EXIF, переносимые golden fixtures и ICC-проверки.
- Регрессионный набор portrait/product/landscape и визуальная оценка пользователем.

Приёмка: полная регрессия; неизменность оригиналов; документированные ресурсные границы;
полный сценарий из §23 на нескольких реальных ARW с одобрением пользователя.
