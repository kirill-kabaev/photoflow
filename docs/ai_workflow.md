# Codex-assisted workflow

Mode A полностью локален в части Python. Codex выступает AI Director в текущем
разговоре. Программа не может вызывать этот разговор самостоятельно.

1. `scan`, `next` / `run --next`: выбор кадра с учётом priority.
2. `analyze`: реальная нейтральная RAW-проявка, измерения и контекст; статус analyzing.
3. Codex открывает `analysis_preview.jpg` и читает context/session_style. Если
   просмотра нет, честно сообщает ограничение; не импортирует фиктивный план.
4. Codex записывает `Plan`: анализ наблюдаемой сцены, неопределённости и рецепт.
   `analysis.preview_sha256` связывает с фактическим превью; `source_sha256` — с RAW.
5. `import-plan` строго проверяет схему/ID/контрольные суммы/родителя и переводит ready.
6. `process`: исходный RAW → новая версия → review. Pending ai_review.json честно
   говорит, что результат ещё не осмотрен; это не завершённая AI-проверка.
7. Codex осматривает before/after и masks overlays, при необходимости полный кадр,
   записывает AIReview с checksum фактического comparison и выполняет import-review.
8. Допустима обоснованная ревизия; инженерные замечания Codex не выдаются за слова
   пользователя. По умолчанию максимум три итерации на запрос, затем review checkpoint.
9. `approve --version --by` только после явного решения пользователя; `export`.

JSON Schema можно получить через `photoflow schema plan|recipe|review`.
`examples/codex_handoff.py` печатает нейтральную структуру плана по context.json:
она не импортируется до заполнения настоящего анализа. Тестовые планы имеют
provider=test_fixture, явно подписаны в отчётах и не являются реальной AI-интеграцией.

## Feedback и восстановление рецепта

Codex сохраняет пользовательский текст в feedback.md текущей версии, вызывает
revise, читает предыдущий анализ/рецепт и checksum feedback. Новый Plan обязан
указать parent_version, feedback_sha256 и объяснить изменения в feedback_applied.
Невыполнимые пожелания перечисляются в unfulfilled_feedback. Изменившийся feedback
между импортом и process блокирует устаревший план.

Для восстановления старого вида берётся старый рецепт, но создаётся новая версия
с текущим родителем и документированным feedback. Старые версии не изменяются.
`session_style.json` — валидированная подсказка AI, а не пресет, автоматически
подставляющий одни числа во все кадры. Снимок стиля сохраняется в каждой версии.

## Внешние AI и модели

Mode B не реализован: нет скрытого провайдера, внешних запросов, загрузки RAW,
бюджетирования или фиктивных ответов. Следующий этап должен отдельно реализовать
opt-in на уменьшенные изображения, модель/provider из конфигурации, секреты из
окружения, строгие ответы, timeouts, bounded retries и лимиты стоимости/запросов.
Это не требуется для текущей работы через Codex.

Семантические модели кожи/волос не установлены. Поддерживаются выбранные AI
эллиптические области; этот факт записывается в анализ, рецепт и отчёт. Они не
заменяют сегментацию при точной ретуши. Генеративные операции отсутствуют.
